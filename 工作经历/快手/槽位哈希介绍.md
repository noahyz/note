## 0. 一句话定义

**SlotHash = 固定槽位表 + 随机评分 + 精确配额**：把“机房/节点的权重（文件比）”离散成“槽位配额”，请求只需 **一次哈希命中槽位**，即可 **O(1)** 返回该槽位对应的节点列表，并且**任何节点变更只影响自身槽位**、扰动可工程化灰度控制。

------

## 1. 为什么要做（业务痛点 → 传统一致性哈希不够用）

你面对的 CDN 点播缓存调度场景，约束非常“反常规”：

- **权重要极准**：比如 30% 文件比就必须是 30% 文件，误差不能超过 1%。 1.自研离散型槽位哈希
- **变更要“无扰动/可控”**：机房故障剔除不能把流量立刻转移到其他机房，避免回源雪崩；新增机房也不能影响老机房，需要灰度、可配置、可人工介入。 
- **允许“非 100%”与“多返回”**：文件比总和可 <100%（空槽兜底三方），也可 >100%（同一槽位返回多个机房作为备份/优先级）。 
- **吞吐要高、资源要省**：要能快速 key→node 映射。

因此你不是在追求“理论最小扰动”，而是在追求**工程可控的零预期扰动**：变更必须**按预期发生**，且能灰度。

------

## 2. 目标拆解

把目标说成 4 条。

1. **精确性**：权重 → 槽位数严格线性对应（配额精确）
2. **单调性**：任何节点变更只影响自身，不牵连其他节点缓存
3. **高性能**：查询 O(1)，更新局部化
4. **工程可控**：灰度窗口、频率、单次迁移量、每日上限可配置

这些是 SlotHash 相对业界方案的“差异化锚点”：它在表格里被定义为**“完美按权重分配、完全仅影响自身槽位、可控零扰动”**。 

------

## 3. 核心设计（3 个关键词：固定槽位、随机评分、精确配额）

### 3.1 固定槽位（把连续区间问题变成离散问题）

将文件 ID 映射空间离散成固定槽位 S（比如 1000 个槽位），**槽位就是最小可控文件区间**。
 这样“文件区间拆分指数爆炸、运维复杂”的问题，转为“调文件比百分比”的简单操作。

### 3.2 随机评分（slot, node → score）

为每个节点在每个槽位上计算一个可复现的随机分数（近似指数分布），用来决定“这个节点更适合占哪些槽”。

### 3.3 精确配额（weight → quota → 槽位数）

把权重直接换算成配额：例如 10 个槽位、权重 20:30:50 → 槽位数 2:3:5，然后按各自槽位得分从高到低去“填坑”，被占了就顺延。
 **结果：槽位数严格等于配额（精确权重）**。

------

## 4. 算法流程

### 4.1 查询（在线路径，极简）

- key **一次哈希命中槽位**
- 直接返回该槽位绑定的节点列表 → **O(1)** 1.自研离散型槽位哈希
- 若槽位为空：返回空，工程侧兜底三方 CDN（严格不扰动）。

### 4.2 权重上调 / 新节点上线（“抢占槽位”，只动自己）

策略：优先占“更空、对我更有利”的槽位

- 为节点构造 `slotDiff`：(slotIndex, 当前槽位节点数, scoreDiff)
- 排序：先槽位节点数少，再 scoreDiff 大（越接近槽位最高分越优先）
- 填充到达到新增配额为止 

### 4.3 权重下调 / 节点下线（“释放槽位”，只动自己）

策略：优先释放“最拥挤、对我最不重要”的槽位

- 构造 `slotScore`：(slotIndex, 当前槽位节点数, 我在该槽位的score)
- 排序：先槽位节点数多，再 score 低
- 释放到达到减少配额为止 

### 4.4 多节点槽位 & 空槽位（显式支持“备份/兜底”）

- 槽位可多节点：命中该槽位可返回多个机房，再按“流量分配比例”二次分发
- 槽位可为空：返回空，兜底三方 CDN
- 这样实现“严格单调/不牵连其他缓存”，把“补偿逻辑”放到工程侧做 

### 4.5 重平衡（让槽位“更均匀”，但必须灰度可控）

目标：尽量填空槽，并让各槽位节点数差值不超过 1；但迁移会影响缓存，所以必须加工程约束。
 典型策略（示例配置）：

- 仅在固定时间窗触发（如 09:00–17:00）
- 每小时一次
- 单次每机房槽位变化不超过 2（基数 100）

------

## 5. 对比点

一句话：**SlotHash 不是在追求“理论最优”，而是在追求“工程可控最优”。**

- 业界常见一致性哈希更倾向“全局均衡/最小扰动”，但在你们场景里会导致**其他机房被动接锅 → 缓存失效 → 回源抬升 → 雪崩风险
- SlotHash 的核心优势是：**权重精确、变更只影响自身、扰动可灰度配置**（表格里就是“完美/完全/零扰动”）
