title: 图的最短路径-floyd算法
---

### 一、定义

全源最短路径算法。在一个带权图上，计算任意两点 i->j 的最短距离。

适用范围：

- 有向/无向图都可以
- 允许负权边
- 不允许负权环。若存在负权环，“最短路”没有意义（可以无限变小），算法可用于检测负权环。

输出：两点之间的距离、以及路径

### 二、思路

核心思想是一个动态规划问题。

```python
INF = float("inf")

def floyd_warshall(graph):
    # 1. 初始化距离矩阵和路径矩阵
    n = len(graph)
    dist = [row[:] for row in graph]
    next = [
        [None if graph[i][j] == INF else j for j in range(n)] for i in range(n)
    ]
    # 2. 三重循环更新距离和路径
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] != INF and dist[k][j] != INF:
                    if dist[i][j] > dist[i][k] + dist[k][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]
                        next[i][j] = next[i][k]
    # 3. 检测负权环
    for i in range(n):
        if dist[i][i] < 0:
            print('图中存在负权环')
            return dist, next, True
    return dist, next, False

graph = [[0,4,3,INF], [INF, 0,INF,2], [-2,INF,0,5], [3, INF, INF, 0]]

dist, next, isExist = floyd_warshall(graph)
print(dist)
print(next)
print(isExist)
```

### 三、缺陷

时间复杂度：O(n^3)

空间复杂度：O(n^2)
