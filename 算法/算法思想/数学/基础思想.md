哈希函数：将任意长度的输入，通过哈希算法可以压缩为某一固定长度的输出。

迭代法：不断使用旧的变量值，递推计算新的变量值。比如二分法、递推、循环

数学归纳法：

```
证明基本情况(通过是 n=1 的时候)是否成立？
假设 n=k-1 成立，再证明 n=k 也是成立的(k 为任意大于 1 的自然数)
```

递归：每次嵌套调用都会让函数体生成自己的局部变量，可以用来保存不同状态下的数值，为我们省去大量中间变量的操作，方便了设计和编程。

数学归纳法：

```
对于n个元素的全排列，所有可能的排列数量是 n*(n-1)*(n-2)*...*2*1,也就是 n!
对于n个元素里取出m(0<m<=n)个元素的不重复排列数量是 n*(n-1)*(n-2)*...*(n-m+1),也就是 n!/(n-m)!

n个元素中取出m个的组合，可能性数量就是n个里取m个的排列数量，除以m个全排列的数量，也就是(n!/(n-m)!)/m!
对于全组合，可能性有 2^n 种

排列考虑了取出的元素之间的顺序，而组合无需考虑这种顺序。
因此，组合适合找到多个元素之间的联系，而不在意他们之间的先后顺序。
```

动态规划：

```
和排列组合等穷举的方法相比，动态规划关注发现某种最优解。如果一个问题无需求出所有可能的解，而是要找到满意一定条件的最优解，那可以使用动态规划来降低求解的工作量。

什么时候使用动态规划：
首先，如果一个问题有很多种可能，看上去需要使用排列或组合的思想，但是最终求的只是某种最优解（例如最小值、最大值、最短子串、最长子串等），此时可以尝试动态规划。
其次，状态转移方程是个关键。可以用状态转移表帮助我们理解整个过程。
```

从树到图，如果节点与节点之间存在距离、价格等，不论是广度优先、深度优先都需要遍历所有可能的路线，然后取最优解。
如果遍历所有可能的通路，因此一个节点可能会被访问多次。这时，就需要图相关的算法了。
