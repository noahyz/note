---
title: CSS中的文档流
---

使一个元素脱离标准文档流有三种方式：

- 浮动
- 绝对定位
- 固定定位

## 一、浮动

```
    <div class="box"></div>
    <div class="box2"></div>
    <div class="container"></div>
    
      .container {
        width: 200px;
        height: 200px;
        background-color: blue;
      }

      .box {
        width: 100px;
        height: 100px;
        background-color: aqua;
        float: left;
      }
      .box2 {
        width: 100px;
        height: 100px;
        background-color: brown;
        float: left;
      }
```

使用 float 属性定义元素在那个方向浮动。只有左右浮动。

脱离文档流后，元素相当于在页面上增加一个浮层来放置内容。此时有两层页面，一层是底层的原页面，一层是脱离文档流的上层页面。

当所有元素同时浮动时，会变成水平摆放，向左或者向右。

当容器不足以横向摆放内容时，会在下一行摆放。

注意，CSS中块级元素默认上下排列，使用浮动可以让其水平排列。

### 清除浮动

当元素设置浮动后，有如下影响：

- 浮动元素会造成父元素高度塌陷
- 后续元素会受到影响

当父元素出现塌陷时，对布局不利，我们需要清除副作用。有如下解决方案：

- 父元素设置高度
- 受影响的元素增加 clear 属性
- overflow 清除浮动
- 伪对象方式

```
    <div class="container">
      <div class="box"></div>
      <div class="box"></div>
      <div class="box"></div>
      <div class="nav"></div>
    </div>
    
      .container {
        background-color: black;
        overflow: hidden;
        clear: both;
      }

      .box {
        width: 100px;
        height: 100px;
        background-color: aqua;
        float: left;
      }

      .nav {
        width: 100px;
        height: 100px;
        background-color: red;
        float: left;
      }
```

## 二、定位

position 属性指定了元素的定位类型

- relative：相对定位
- absolute：绝对定位
- fixed：固定定位

其中，绝对定位和固定定位会脱离文档流。

设置定位之后，可以使用四个方向值进行调整位置：left、top、right、bottom。

设置定位之后，相对定位和绝对定位 是相对于具有定位的父级元素进行位置调整，如果父级元素不存在定位，则继续向上逐级寻找，直到顶层文档。

#### 堆叠顺序

z-index 属性设置元素的堆叠顺序，拥有更高堆叠顺序的元素总是会处于堆叠顺序较低的元素的前面。

```
    <div class="box1"></div>
    <div class="box2"></div>
    
    .box1 {
        width: 200px;
        height: 200px;
        background-color: red;
        position: absolute;
        z-index: 7;
      }

    .box2 {
        width: 300px;
        height: 300px;
        background-color: green;
        position: absolute;
        z-index: 5;
      }
```
