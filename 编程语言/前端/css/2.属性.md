### 一、字体属性

```
color: 规定文本的颜色
div{ color:red;}
div{ color:#ff0000;}
div{ color:rgb(255,0,0);}
div{ color:rgba(255,0,0,.5);}

font-size: 设置文本的大小
p {font-size:14px;}

font-weight：设置文本的粗细
bold: 粗体字符；bolder：更粗的字符；lighter：更细的字符
100-900: 定义由粗到细，400等于默认，700等同于bold
H1 {font-weight:normal;}
div{font-weight:bold;}
p{font-weight:900;}

font-style：文本的字体样式
normal：默认值
italic：定义斜体字

font-family: 指定一个元素的字体
font-family:"Microsoft YaHei","Simsun","SimHei";
```

### 二、背景属性

```
background-color：设置背景颜色

background-image：设置背景图片
background-image: url("images/img1.jpg");

background-position：设置背景图片显示位置，设置背景图像的起始位置，其默认值为：0% 0%
left top: 左上角
left center：左中
left bottom：左下
center 和 right 上同
x% y% 第一个值为水平位置，第二个值为垂直位置。左上角为 0% 0%，右下角为 100% 100%
xpos ypos：单位是像素


background-repeat：设置背景图片如何填充
repeat：默认值；repeat-x：只向水平方向平铺；repeat-y：只向垂直方向平铺；no-repeat：不平铺
如果背景容器比图片大，则会使用相同图片填充


background-size：设置背景图片大小属性
background-size: 100% 100%;
length：设置背景图片的宽度和高度，第一个值是宽度，第二个值是高度，如果只设置一个，第二个值为 auto
percentage：设置相对位置区域的百分比，第一个值是宽度，第二个值是高度，如果只是设置一个，第二个值是 auto
cover：保持图片纵横比并将图片缩放成完全覆盖背景区域的最小大小
contain：保持图片纵横比并将图片缩放成适合背景定位区域的最大大小
```

### 三、文本属性

```
text-align: 指定元素文本的水平对齐方式
h1 {text-align:center}
left：文本居左排列，默认值；right：把文本排列到右边；center：把文本排列到中间


text-decoration：规定添加到文本的修饰，下划线、上划线、删除线等
h1 {text-decoration:overline}
underline: 定义下划线；overline：定义上划线；line-through：定义删除线


text-transform：控制文本的大小写
h1 {text-transform:uppercase;}
captialize：定义每个单词开头大写
uppercase：定义全部大写字母
lowercase：定义全部小写字母


text-indent：规定文本块中首行文本的缩进
text-indent:50px;
允许负值。如果是负值，将第一行左缩进
```

### 四、表格属性

```
border：指定CSS表格边框
table, td {
	border: 1px solid black;
}

border-collapse: 表格的边框是否被折叠成一个单一的边框
table {
	border-collapse: collapse;
}

width、height：定义表格的宽度和高度
table {
	width: 100%;
	height: 50px;
}

表格文字对齐：
text-align：设置水平对齐方式，向左、右、或中心
vertical-align：设置垂直对齐方式
td {
	text-align: right;
	vertical-align: bottom;
}

表格填充：如果在表的内容中控制空格之间的边框，可以使用 td 和 th 元素的填充属性
td {
	padding: 15px;
}

表格颜色：指定边框的颜色，和 th 元素的文本和背景颜色
td {
	background-color: green;
	color: white;
}
```

### 五、子代选择器

```
后代选择器：选择所有被E元素包含的F元素，中间用空格隔开
ul li {
	color: green;
}

子代选择器：选择所有作为E元素的直接子元素F，对更深一层的元素不起作用，用>表示
div>a{
	color: red;
}
```



其他属性

transition 属性

```
transition：属性是 CSS 中用于创建平滑过渡效果的属性，允许属性值在一段时间内逐步从一个状态变为另一个状态。它常用于在用户交互（如鼠标悬停、点击等）时，为元素添加动态变化的效果。
transition: [property] [duration] [timing-function] [delay];

property（必选）：指定要应用过渡效果的 CSS 属性。
示例：width、background-color、all。
使用 all 可以让所有支持过渡的属性应用过渡效果。

duration（必选）：过渡持续时间，单位为秒（s）或毫秒（ms）。
示例：1s、500ms。

timing-function（可选）：指定过渡的时间曲线（加速或减速效果）。
常见值：
ease（默认值）：先慢后快再慢。
linear：匀速过渡。
ease-in：慢慢开始。
ease-out：慢慢结束。
ease-in-out：开始和结束都慢。
cubic-bezier(x1, y1, x2, y2)：自定义贝塞尔曲线。

delay（可选）：过渡的延迟时间，单位为秒（s）或毫秒（ms）。
示例：0s（无延迟）、200ms。
```

opacity 属性

```
opacity 属性用于设置元素的透明度（即不透明度）。它通过一个数值指定元素的透明程度，从完全透明到完全不透明。
opacity: <value>;

<value>：一个介于 0 和 1 之间的数值。
0 表示完全透明（不可见）。
1 表示完全不透明（默认值）。
中间的数值（如 0.5）表示半透明。
```
