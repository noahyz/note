### 大模型中 token 的理解

大模型的工作内容：一次添加一个词。本质上说，chatgpt 做的是针对任何文本产生“合理的延续”。所谓合理，就是人们看到诸如数十亿个网页上内容后，可能期待别人会这样写。

严格意义上说，每次添加的是一个 token。这个token可能是我们传统理解的一个完整的单词，可能是一个单词组合，甚至可能是单词的一部分。

上下文窗口（context window）指的是大模型可以处理 token 数量，上下文越大，能处理的token越多。能处理的token越多，大模型对信息的理解就越充分，生成的内容就越接近我们需要的结果。

一般的AI模型也是通过token来计费的。

### 随机性

对文本进行合理延续时，我们需要从一个带有概率的词列表中进行选择。那如何选择呢？

如果一直选择概率较高或排名最高的词，将会是一篇非常平淡的文章。因此选择的时候会带有一些随机性。

有了随机性，也就意味着对于同样的提示词，我们每次得到的内容可能会不同。我们用“温度”表示随机性强弱。

在 OpenAI 的 API 中，温度这个参数越小，表示确定性越强。参数值越大，表示随机性越强。也就是说温度越高越活跃。

### 向量

我们向大模型提供的是待补充的字符串，大规模内部处理的是向量。现在大部分AI算法只支持向量。因此需要将字符串、图片、视频等数据转换为向量。

字符串转成向量的步骤，第一步是 One-Hot 编码，第二步是把编码的结果进行压缩。

One-Hot 编码，就是将离散的分类值转换为二进制向量。

编码之后的结果一般是稀疏存储，占用特别大，因此我们需要压缩，得到我们想要的 embedding。获取 embedding 的方法一般有两种：

- 降维。技术比如：主成分分析（Principal component analysis）
- 把 embedding 训练成神经网络。也就是将我们前一步的向量送给一个神经网络，得到最终的压缩过的向量。

在大规模中，embedding 是一种将高维数据（文本、图像、视频等）转换为低维向量表示的技术。核心思想是将离散数据映射到连续的向量空间，使得相似的数据点在向量空间中的距离较近，而不相似的数据点距离较远。
